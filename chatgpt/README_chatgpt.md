# ChatGPT で汎用マニュアルを使うためのパッケージ（2026-10-24 作成・原典 v63）

本パッケージは3つの貼り付け用ファイルと本書（手順と限界の説明）から成る。

| ファイル | 貼る場所 | 効く範囲 |
|---|---|---|
| `chatgpt_custom_instructions.txt`（971字） | ChatGPT の **設定 → パーソナライズ → カスタム指示** の「ChatGPT にどのように応答してほしいですか」欄 | **アカウント内の新規チャット全体**（これが唯一のアカウント全体適用の仕組み） |
| `chatgpt_project_instructions.md` | 各**プロジェクトの「指示」欄**、または **GPTs（自作のカスタム ChatGPT）の Instructions 欄** | そのプロジェクト／その GPT の全チャット |
| `chatgpt_session_paste.md` | 個別チャットの**最初のメッセージとして貼り付け** | その1チャットのみ |

- カスタム指示（＝設定画面で登録する、全チャット共通の常時指示）
- プロジェクト（＝チャットをまとめる入れ物。指示とファイルを共有できる）
- GPTs（＝指示と知識ファイルを固定した自作のチャットボット）
- メモリ（＝ChatGPT が会話をまたいで記憶する機能）

## 推奨セットアップ手順（1ステップずつ）

1. まず `chatgpt_custom_instructions.txt` の全文をコピーし、設定 → パーソナライズ → カスタム指示 に貼って保存する。**ここまでで、以後の新規チャット全部に短縮版が常時適用される。**
2. 業務で使う各プロジェクトを開き、「指示」欄に `chatgpt_project_instructions.md` の全文を貼る（欄の上限を超えたら、§4〜§6 を削って短くする）。
3. プロジェクト外の重要なチャットでは、冒頭に `chatgpt_session_paste.md` を貼る。
4. （任意）新規チャットで「このパッケージの規則一式を記憶して、今後の会話でも適用して」と伝えてメモリに登録する——ただしメモリの再現は不確実で、長い規則は要約・欠落されうる【未確認・推測：メモリの忠実度は仕様非公開】。

## 原典との対応と、**再現できないもの**（隠さない）

| Claude 環境の仕組み | ChatGPT での代替 | 忠実度 |
|---|---|---|
| L0 コアカード常時適用（設定欄/CLAUDE.md） | カスタム指示（短縮版971字）＋プロジェクト指示（全文） | **中**：カスタム指示は文字数制限（従来約1,500字/欄。変動あり——貼り付け時に画面の上限表示を確認）のため短縮版。全文はプロジェクト単位でのみ常時適用できる |
| フックによる機械検査（毎ターンの関門注入・出力契約検査・発行ガード） | **代替なし**。§2 の自己検査のみ | **低**：機械的強制は存在しない。原典 §6 のとおり自己検査は取りこぼしうる |
| 発行のたびの自動更新（[Code] の SessionStart フック） | 「マニュアル更新」キーワードでブラウジング取得（2URL・?t=付き） | **中**：自動では走らない。ユーザーが打鍵したときのみ |
| 毎朝の状況ボード・Routine（定時実行） | ChatGPT の「タスク」機能（定時にチャットを実行する機能）で手動設定可 | **低**：セッション一覧 API に相当するものが無く、他チャットの状態は見えない |
| 受け口（Google Drive claude_handover/）への引き継ぎ保存 | ChatGPT は Drive へ書き込めない（2026年1月時点の仕様知識【未確認・推測：最新のコネクタ事情は要確認】）。引き継ぎ文書を生成させ、ユーザーが保存する | **低** |
| 発行権マーカー・条文改訂の統制（§0-4） | 原典どおり「ChatGPT 側では提案まで。改訂・発行は配布元（本リポジトリ）でのみ行う」を §7 に内蔵 | 高 |

**結論：アカウント全体へ「貼り付け1回」で全文を常時適用する手段は ChatGPT に存在しない。** 最も近いのは「カスタム指示に短縮版＋各プロジェクトに全文」の2段構えである。「現在のこの環境と全く同じ」にはならない——差分は上表のとおり。

## 更新の運用

原典が v64 以降に上がったら、本パッケージも作り直す（配布元リポジトリの `chatgpt/` が正本）。ChatGPT 側では「マニュアル更新」と打てば最新 L0 を取得して適用する規則を内蔵済み（ブラウジングが使える会話のみ）。
