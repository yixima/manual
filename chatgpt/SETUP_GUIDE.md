# はじめての方へ——ChatGPT 版マニュアルの導入と使い方（運用手順書）

作成日：2026-10-24 ／ 原典：汎用マニュアル v63

このパッケージは、AI アシスタント「ChatGPT」に、仕事用の品質ルール（汎用マニュアル）を守らせるための**貼り付けテキスト集**です。プログラミングの知識は不要です。やることは「コピーして、決まった場所に貼る」だけです。

---

## 0. 同梱ファイル一覧（どれを何に使うか）

| ファイル名 | 役割 |
|---|---|
| `SETUP_GUIDE.md` | 本書。最初に読む |
| `chatgpt_custom_instructions.txt` | 【手順1で使う】アカウント全体に効く短縮版 |
| `chatgpt_project_instructions.md` | 【手順2で使う】プロジェクト用の全文版 |
| `chatgpt_session_paste.md` | 【手順3で使う】個別チャット用（先頭に発動の合図文つき） |
| `README_chatgpt.md` | 技術的な対応表と限界の説明（読むだけ・上級者向け） |
| `setup_guide_chatgpt.pdf` | 本書の清書版 PDF（印刷・配布用） |
| `kinou_ichiran_v63.pdf` | マニュアル本体の機能一覧 PDF（読むだけ） |

**最初に知っておくこと（重要）**：ChatGPT には「1回貼れば全部に効く」仕組みがありません。効かせる範囲ごとに貼る場所が3つに分かれています。手順1だけでも効果がありますが、仕事で使うプロジェクトには手順2まで行うことを勧めます。

---

## 1. 【手順1・必須／所要約3分】アカウント全体に短縮版を入れる

「カスタム指示」（＝ChatGPT の設定画面にある、全ての新しいチャットに毎回適用される指示欄）に貼ります。

1. パソコンかスマホで ChatGPT を開き、ログインする。
2. 画面の自分のアイコン（または左下の自分の名前）を押す。
3. メニューから **「設定」** を開く。
4. **「パーソナライズ」**（または「カスタム指示」）を開く。
5. 「ChatGPT にどのように応答してほしいですか」という入力欄を探す。
6. `chatgpt_custom_instructions.txt` をメモ帳などで開き、**全文をコピー**して、その欄に**貼り付ける**。
7. **保存**を押す。
8. 確認：**新しいチャット**を開き、「今日の日付を教えて」と送る。応答に【確認済】などのラベルや「— 状態：…」の行が付いていれば、適用されています。

> 欄に入り切らない（文字数超過の表示が出る）場合：このテキストは971字で、従来の上限（約1,500字）には収まります。それでも超過が出たら、末尾の「マニュアル更新」の2行を削って貼ってください。

## 2. 【手順2・推奨／プロジェクトごとに約2分】仕事のプロジェクトに全文版を入れる

「プロジェクト」（＝ChatGPT でチャットをまとめるフォルダのような機能。指示とファイルを配下の全チャットで共有できる）に貼ります。

1. ChatGPT の左側メニューで、対象の**プロジェクト**を開く（無ければ「＋」で新規作成）。
2. プロジェクト名の近くにある **「指示」（Instructions）** を開く。
3. `chatgpt_project_instructions.md` の**全文をコピー**して貼り付け、保存する。
4. 確認：そのプロジェクト内で新しいチャットを開き、「ルール点検して」と送る。マニュアルの再点検結果が返ってくれば適用されています。

> 仕事のチャットは、できるだけプロジェクトの中で始めてください。全文版が常時効くのはプロジェクト内だけです。

## 3. 【手順3・必要なとき】プロジェクト外のチャットで使う

プロジェクトに入れないチャット（単発の相談など）では、**チャットの最初のメッセージ**として `chatgpt_session_paste.md` の全文を貼り付けて送信します。「マニュアル（v63由来・ChatGPT版）を適用しました」と返ってくれば成功です。効くのはそのチャットだけです。

## 4. 日常の使い方（貼ったあと、何が変わるか）

- **事実に印が付きます**：【確認済】＝出典つきで確かめた／【未確認・推測】＝確かめていない／【不明】＝分からない。**【未確認・推測】の内容は、そのまま社外に出さず、必ず元資料で確認してください。**
- **応答の末尾に状態の行が付きます**：「— 状態：完了　次：〇〇」。「次：」に書かれたことが、あなたのやることです。
- **空欄をごまかさなくなります**：調べても分からなかった項目には「どこを調べて無かったか」が書かれます。書かれていない空欄を見つけたら「調べて埋めて」と返してください。
- **質問は一度に一つだけ来ます**。答えると作業が続きます。

### 覚えておく合言葉（チャットにそのまま打つ）

| 打つ言葉 | 起きること |
|---|---|
| `マニュアル更新` | 配布元から最新版を取得して適用（ウェブ閲覧が使える会話のみ） |
| `マニュアル確認` / `ルール点検して` | 直前の応答を自己点検させる |

## 5. 困ったとき（Q&A）

- **Q. ラベルや状態行が付かない** → そのチャットにルールが届いていません。プロジェクト外なら手順3の貼り付けを。カスタム指示が保存されているか（手順1の8）も確認。
- **Q. 途中からルールを守らなくなった** → 長いチャットでは忘れが起きます。`マニュアル確認` と打つか、手順3のテキストを貼り直してください。
- **Q. 「全く同じ」になりますか？** → なりません。Claude 環境にある機械的な自動チェック・自動更新・定時監視は ChatGPT に存在せず、ルールは ChatGPT の自己管理に委ねられます（詳細は `README_chatgpt.md` の対応表）。**最後の安全網はあなた自身の確認です。**
- **Q. マニュアルが新しくなったら？** → `マニュアル更新` と打つ（会話単位）。カスタム指示・プロジェクト指示は自動では変わらないので、配布元から新パッケージを受け取って貼り直してください。

## 6. 用語集（本書で使った言葉）

- **カスタム指示**：ChatGPT の設定画面にある、全チャット共通の常時指示欄。
- **プロジェクト**：チャットをまとめる入れ物。指示とファイルを配下の全チャットで共有できる。
- **GPTs**：指示を固定した自作のチャットボット。プロジェクトの代わりに使える（作成画面の Instructions 欄に手順2と同じものを貼る）。
- **ラベル**：事実の確からしさを示す印（【確認済】など）。
