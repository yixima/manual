# `handover/` ＝ 引き継ぎの受け口

このディレクトリに引き継ぎファイル（`*.md`）を置くと、**次のセッションが開始した時点で自動的に受領確認が行われる**。
ユーザーが「ちゃんと引き継げていますか」と質問する必要はない（L1 §10-5）。

## 使い方（3ステップ）

1. **引き継ぎ元のセッションで作る**

   ```
   python3 tools/make_handover.py --auto handover/<名前>_handover_<YYYYMMDD>_v1.md
   ```

   会話の原文・実行したコマンド・触ったファイル・失敗・未完了は、セッションの記録から**要約せずに**自動で入る。
   残るのは `【要記入】` の箇所＝**理由**だけである（理由は記録に残らないため、機械には書けない）。

2. **`【要記入】` を埋めてから、検査を通す**

   ```
   python3 tools/make_handover.py --check handover/<ファイル名>
   ```

   `【要記入】` が1つでも残っていれば不合格になる。**不合格のまま渡さない。**

3. **次のセッションを開く。** 受領確認は自動で走る。手で確かめたいときは:

   ```
   python3 tools/make_handover.py --receipt handover/<ファイル名>
   ```

## 注意

- ここに置いたファイルは **git の追跡対象外**である（`.gitignore`）。会話の原文がそのまま入るため、
  公開リポジトリへ載せない。**共有したいときは、中身を確認したうえで明示的に `git add -f` する。**
- 複数ある場合は**最も新しいもの**が受領される。
- 引き継ぎファイル以外の `.md`（この README を含む）は受領対象にならない。判定は「第1章の見出しを持つか」で行う。
