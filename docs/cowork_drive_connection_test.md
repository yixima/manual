# Cowork の接続テスト（1回だけ・そのまま貼る）

> **使い方**：Cowork のセッションを開き、「―― ここから ――」から「―― ここまで ――」までを
> **そのまま貼り付けて送信**するだけ。返ってくる答えを、こちらへ転記してください。
>
> **チャットのテストとの違い**：チャットでは「書く→読み戻す」だけを確かめた。
> Cowork では**それに加えて「他の環境が置いたものを受け取れるか」も確かめる**。
> これが成立して初めて、`[Code]` → `[Cowork]` の引き継ぎが成立する。
>
> **受信テスト用のファイルは、既に Claude Code から受け口へ置いてある**（`_cowork_receive_test.md`）。

---

―― ここから ――

Google ドライブの `claude_handover` フォルダを使って、次の【A】【B】を順に実行してください。
**コードやコマンドは表示せず、結果だけを日本語で報告**してください。

## 【A】受け取れるか（他の環境が置いたものを読む）

`claude_handover` フォルダにある **`_cowork_receive_test.md`** を、
**生のまま（＝元のバイト列として）取得**し、次を報告してください。

1. 取得できたか。できなければ**エラーの原文をそのまま**。
2. **バイト数**と **sha256**（＝1文字でも違えば変わる照合値）。
3. 本文の**5行目**をそのまま書き写す（この行に、全角スペースと半角スペース2つが含まれている。**そこが変化していないかを見たい**）。
4. 参考：**検索機能が返す抜粋**でも同じファイルを見て、生取得の内容と**違っていたかどうか**。

## 【B】置けるか（自分で書いて、読み戻す）

下の本文を、`claude_handover` フォルダに **`_cowork_send_test.md`** という名前で保存してください。

- 形式は **text/markdown（平文）**。
- **Google ドキュメント等への自動変換は必ず無効**にしてください。

保存する本文（この4行だけ。前後に何も足さない。**末尾に改行を1つ付ける**）:

```
# Cowork からの送信テスト
> 引用行。**強調**と `行内コード`。
| 列A | 列B |
| 値1 | 値2 |
```

保存したら、**生のまま取得し直して**、次を報告してください。

5. 保存できたか。できなければ**エラーの原文をそのまま**。
6. 読み戻した本文の**バイト数**と **sha256**。
7. 保存前と読み戻し後で **sha256 が一致したか**。

## 【C】共通

8. 実際に使えた機能の名前（保存・検索・生取得のそれぞれ）。
9. Cowork の**作業フォルダ（ローカルのファイル）を経由したか、ドライブへ直接読み書きしたか**。
10. できなかったことがあれば、**表示された文言をそのまま**（推測で補わない）。

## 判定基準（こちら側で照合する値）

| 項目 | 期待値 |
|---|---|
| 【A】`_cowork_receive_test.md` のバイト数 | **196** |
| 【A】同 sha256 | `3d78a42ab87299505b27bca44418a11cc87b9d50ea77f9aa8095b13927592487` |
| 【B】`_cowork_send_test.md` のバイト数 | **115** |
| 【B】同 sha256 | `af367a3d78d78d7350f3ab070214f06b16031aeba76524cdae53a1fe62cca4c3` |

- **【A】が一致** → `[Code]` が置いたものを `[Cowork]` が原本のまま受け取れる。**受信が成立。**
- **【B】が一致** → `[Cowork]` が原本のまま置ける。**送信が成立。**
- **【B】の sha256 が期待値と違うが、保存前後で一致している場合** → 貼り付けの時点で本文が変わっただけであり、
  **ドライブの問題ではない**。保存前後が一致していれば送信は成立している。
- **どちらかが不成立** → Cowork だけ受け口へ置けない／読めない。その場合は Cowork の扱いを条文で分ける。
