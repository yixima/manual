# チャットの接続テスト（1回だけ・そのまま貼る）

> **使い方**：claude.ai の**新しいチャット**を開き、下の「―― ここから ――」から「―― ここまで ――」までを
> **そのまま貼り付けて送信**するだけ。返ってくる5つの答えを、こちらへ転記してください。
>
> **何を確かめるのか**：チャットから Google ドライブへ**書けるか**、書いたものを**元のまま読み戻せるか**。
> この2つが成立すれば、全環境で自動的に引き継ぐ仕組みが動きます。成立しなければ、別の受け口へ切り替えます。

---

―― ここから ――

Google ドライブの `claude_handover` フォルダ（既にあります）を使って、次の3つを順に実行してください。
**コードやコマンドは表示せず、結果だけを日本語で報告**してください。

**1. 保存する**

下の本文を、`claude_handover` フォルダに **`_connection_test.md`** という名前で保存してください。

- 形式は **text/markdown（平文）**。
- **Google ドキュメント等への自動変換は必ず無効**にしてください（変換すると記号が作り替えられ、原本ではなくなります）。

保存する本文（この4行だけ。前後に何も足さない）:

```
# 接続テスト
> 引用行。**強調**と `行内コード`。
| 列A | 列B |
| 値1 | 値2 |
```

**2. 読み戻す**

いま保存したファイルを、**生のまま（＝元のバイト列として）取得し直して**ください。
「自然言語表現として読む」経路ではなく、**生のまま**取得できるかどうかが要点です。

**3. 突き合わせる**

保存した本文と、読み戻した本文の **sha256（＝1文字でも違えば変わる照合値）を計算して比較**してください。

**報告してほしいこと（この5つだけ。推測を混ぜず、実際に起きたことを書く）**

1. 保存できたか。できなければ**エラーの原文をそのまま**。
2. 生のまま取得できたか。できなければ、代わりに何が取得できたか。
3. sha256 は一致したか（一致／不一致）。不一致なら、**最初に違っていた箇所**。
4. 実際に使えた機能の名前（保存・検索・取得のそれぞれ）。
5. 上記のどれかができなかった場合、**その理由として表示されたもの**（推測ではなく、表示された文言）。

## 結果の読み方（こちら側の判断基準）

| 結果 | 意味 | 次にすること |
|---|---|---|
| 1〜3 すべて成立（sha256 一致） | **全環境で完全に成立する。** 指紋による受領確認がチャットでも使える | 発行へ進む |
| 保存も取得もできるが sha256 が不一致 | 中身は届くが書式が変わる経路しかない。**受領は「件数一致」で判定する**（3段階判定の②） | 発行へ進む。ただし原文の細部は原本と異なりうると明記する |
| 保存できない | チャットからは受け口へ置けない。**別の受け口**（プロジェクトの共有資料など）へ切り替える | 受け口を選び直してから発行 |
